# Software Engineering Experiments

A practical portfolio of software engineering coursework covering development processes, design, testing, architecture, maintenance, quality assurance, and project planning. The repository brings together concise reports, diagrams, code samples, and small application demonstrations.

## Experiments

| 02 | [Design Patterns Implementation](<Experiment-02-Design Patterns Implementation/>) | Explore Factory, Observer, and Singleton patterns in Java. |
| 03 | [Testing and Validation Techniques](<Experiment-03-Testing and Validation Techniques/README.md>) | Apply testing techniques to a calculator example. |

## Repository contents

Depending on the experiment, its folder may contain a report, source code, diagrams, screenshots, or supporting documents. Technologies represented in the examples include Java, Python, Flask, MySQL, HTML, CSS, and JavaScript, along with JUnit, pytest, and static analysis tools.

## Using the materials

1. Select an experiment from the table above.
2. Review its README or report for the objective, scope, and instructions.
3. Follow any experiment-specific setup requirements before running code.

The [Experiment 09 documentation](<Experiment-09-Software Engineering Tools & Technologies/README.md>) includes setup instructions for its Flask and MySQL demonstration. The [Experiment 11 documentation](<Experiment-11-Software Quality Assurance/README.md>) describes how to run its Python example, tests, and analysis tools.

## Intended use

These materials are provided for educational and reference purposes. Each exercise is self-contained; requirements, configuration, and implementation details are documented in its folder where applicable.
